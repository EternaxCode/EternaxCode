# 01. Tech Stack

## Core Framework
- **Next.js (v14)**: React framework for production. Used here primarily for its routing and build optimization features.
- **React (v18)**: UI library.
- **TypeScript**: Static typing for improved developer experience and code safety.

## Styling & Animation
- **TailwindCSS (v4)**: Utility-first CSS framework for rapid UI development.
- **Framer Motion**: Powerful animation library used for page transitions (`AnimatePresence` in `_app.tsx`) and UI element animations.
- **CSS Modules / Global CSS**: Used for specific visual effects like the Glassmorphism variables (`styles/glassPane.css`).

## 3D & Graphics
- **Three.js**: The base 3D library.
- **React Three Fiber (R3F)**: A React renderer for Three.js, allowing declarative 3D scenes.
- **React Three Drei**: Useful helpers for R3F (cameras, controls, loaders).

## Key Libaries
- **Lucide React**: Icon set.
- **Lodash**: Utility functions.
- **Classnames**: Conditional class joining.

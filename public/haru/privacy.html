개인정보처리방침

어떤 정보를 왜 처리하는지, 보관 위치와 삭제 방법을 안내합니다.

1. 처리자와 문의

ETERNAXCODE는 Haru - Japanese의 개인정보처리자입니다. 개인정보 열람·정정·삭제·처리정지 및 문의는 개인정보 보호 담당자에게 support@eternaxcode.com으로 요청할 수 있습니다. 본 방침은 Haru 앱·학습 웹서비스에 적용됩니다. Apple·Google 로그인/스토어, 외부 공식 학습 자료 및 캘린더 서비스에는 각 사업자의 별도 정책도 적용됩니다.

2. 처리 항목과 목적

로그인을 선택하면 Firebase 사용자 ID, 로그인 제공자 식별자, 제공된 이름·이메일·프로필 사진, 계정 생성·접속 관련 정보를 계정 확인과 동기화에 이용합니다. 일반 과정의 학습 진도·복습 일정·답안 결과·학습량을 클라우드 동기화에 이용합니다. 별도 입문 과정, 필기 입력, 일부 학습 설정·시험 진행 상태는 기기에 저장되며 모든 기록이 클라우드에 동기화되지는 않습니다. 필기 압력이나 필체를 신원 확인용 생체정보로 분석하지 않습니다.

3. 구독·고객지원 정보

구독 확인을 위해 계정 ID와 연결된 상품 ID, 거래 식별자·구매 토큰, 스토어, 테스트/운영 환경, 만료·취소 상태와 검증 시각을 서버에서 처리합니다. 결제 카드번호·계좌 비밀번호는 Haru가 받거나 저장하지 않습니다. 결제는 스토어가 처리합니다. 고객지원 시 회신 이메일, 문의 내용 및 사용자가 제출한 주문 정보·진단자료를 처리합니다. 비밀번호·전체 카드번호·주민등록번호를 보내지 마세요. 웹/API 제공 과정에서 IP 주소, 브라우저·기기 정보, 요청 시각 등 기술적 접속정보가 호스팅 사업자에 의해 처리될 수 있습니다.

4. 선택 기능과 법적 근거

회원 서비스의 이행, 사용자가 요청한 동기화·구독 검증, 보안 유지 및 법령상 의무를 위해 필요한 범위에서 처리합니다. 별도 동의가 필요한 처리는 해당 기능에서 동의를 받습니다. 게스트 학습은 로그인 없이 가능하지만 웹 접속에 필요한 기술적 정보는 처리될 수 있습니다. 알림 권한은 사용자가 알림을 켤 때 요청하며 시간·사용 여부는 해당 기기에 저장합니다. 서버에 푸시 토큰이나 알림 시간을 수집하지 않습니다. 캘린더 파일을 추가하면 선택한 캘린더 사업자의 정책이 적용됩니다. 광고 추적 SDK나 광고 맞춤화를 위한 개인정보 판매는 사용하지 않습니다.

5. 위탁·외부 서비스와 보관 위치

Google LLC의 Firebase Authentication을 로그인 관리에, Cloud Firestore를 계정·학습·구독 데이터 저장에 이용합니다. Firestore 데이터베이스 위치는 대한민국 서울(asia-northeast3)입니다. Firebase Authentication은 미국에서 처리됩니다. Vercel Inc.는 학습 웹/API 호스팅과 보안·전송을 담당합니다. EternaxCode의 정적 소개·정책 사이트는 GitHub Pages(GitHub, Inc.)에서 제공됩니다. Apple·Google 스토어는 자체 결제·환불 처리를 위한 독립적인 사업자이며 Haru에는 권한 확인에 필요한 결과가 전달됩니다. 법령이나 별도 적법한 근거 없이 다른 제3자에게 이용자 정보를 판매하거나 공개하지 않습니다.

6. 국외 처리 안내

Firebase Authentication: 수령자 Google LLC, 국가 미국, 항목 로그인 식별자·이메일·제공된 프로필 및 접속정보, 목적 인증·계정 관리·보안, 시기/방법 로그인·인증 요청 시 암호화 통신, 보유 기간 계정 유지 및 삭제 처리에 필요한 기간. Google의 개인정보 문의 창구는 policies.google.com/privacy에 안내되어 있습니다. Vercel Inc.와 GitHub, Inc.: 미국 소재 사업자로, 웹/API 및 정책 페이지 요청 시 IP·기기/브라우저 정보 등 접속정보가 네트워크를 통해 전달됩니다. 전송·보안·로그 처리 위치는 글로벌 인프라와 하위처리자 구성에 따라 달라질 수 있습니다. Vercel 문의는 privacy@vercel.com, GitHub 문의는 docs.github.com의 개인정보 문의 절차를 따릅니다. 호스팅 사업자별 처리 위치·보관 정책은 아래 공식 문서를 참고할 수 있으며 문의 시 확인을 도와드립니다. 계약 이행에 필요한 위탁·보관은 관련 법령상 요건에 따라 공개·고지하며, 별도 동의가 필요한 이전은 별도로 안내합니다. 국외 인증 처리를 원하지 않으면 로그인하지 않고 게스트 기능을 이용할 수 있습니다. 기존 계정의 삭제·처리정지 요청도 가능하며, 이 경우 계정 동기화·구독 검증 기능은 제한될 수 있습니다. 웹 호스팅 접속정보의 처리를 원하지 않으면 해당 웹 페이지 접속을 중단해야 합니다.

7. 보유 기간과 삭제

계정·일반 과정 클라우드 학습 기록은 계정 유지 동안 보관하며 앱의 회원탈퇴 절차로 삭제할 수 있습니다. 서버에서 로그인 계정, 학습 기록, 구독 복원용 구매 토큰과 연결 정보를 함께 정리합니다. 일시적인 오류로 정리가 끝나지 않으면 요청 접수 상태를 안내하고 정기 작업으로 재시도합니다. 기기 전용 기록은 앱/사이트 데이터 삭제로 제거할 수 있습니다. 테스트 환경 구매 검증 이력은 탈퇴 시 삭제합니다. 운영 환경의 계약·결제 확인에 필요한 최소 검증 이력은 분리 보관하며, 탈퇴 요청일과 최종 확인된 계약 종료·검증 시점 중 늦은 시점부터 5년 후 자동 삭제 대상으로 처리합니다. 분쟁 등 법률상 추가 보존이 필요한 경우 해당 사유가 해소될 때까지 목적을 제한하여 보관합니다. 따라서 탈퇴했다고 모든 거래 확인 기록이 즉시 삭제되는 것은 아닙니다. 삭제 요청 시 구독 복원·환불 분쟁·법령상 보존 필요를 확인하여 불필요한 정보는 지체 없이 삭제하고, 보존이 필요한 정보는 목적을 제한하여 보관합니다. 전자상거래법상 운영자에게 보존 의무가 적용되는 계약·청약철회 및 대금결제·공급 기록은 5년, 소비자 불만·분쟁 기록은 3년 보관합니다. 문의를 이러한 기록으로 보관할 때 그 목적 외 이용을 제한합니다. 스토어가 독립적으로 보관하는 원결제 기록에는 스토어의 정책과 법적 의무가 적용됩니다. 전자 파일은 복구하기 어려운 방식으로 파기하고 종이 자료가 있으면 분쇄 등으로 파기합니다.

8. 권리 행사와 아동

앱 프로필의 회원탈퇴, 또는 support@eternaxcode.com을 통해 개인정보 열람·정정·삭제·처리정지 등을 요청할 수 있습니다. 계정 보호를 위한 최소한의 본인 확인 후 처리하며, 법률상 제한이 있으면 사유를 안내합니다. 법정대리인·수임인도 권한 확인 후 요청할 수 있습니다. 새 로그인 전에 만 14세 이상 여부를 스스로 확인하도록 하며 생년월일은 수집하지 않습니다. 만 14세 미만 아동을 위한 법정대리인 동의 절차는 제공하지 않으므로 만 14세 미만은 계정 가입·클라우드 기능을 이용하지 말아 주세요. 동의가 필요한 아동의 개인정보가 수집된 사실을 알게 된 경우 고객지원으로 알려 주시면 확인 및 삭제 등 필요한 조치를 합니다.

9. 안전조치와 로컬 저장소

접근권한 최소화, 인증된 관리자 제한, 암호화된 통신, 서버 측 스토어 검증 및 클라이언트의 구매 기록 직접 접근 차단을 적용합니다. 세션·학습 저장을 위해 브라우저 로컬 저장소와 서비스워커 캐시를 사용합니다. 삭제하거나 차단하면 자동 로그인·오프라인 학습·기기 기록이 사라지거나 작동하지 않을 수 있습니다. 개인 기기를 잠그고 계정을 공유하지 않는 것을 권장합니다.
